# SOTABuilder

SOTABuilder 是一个以横屏为主、中文界面的浏览器游戏，玩家将扮演一家 AI 公司的 CEO，在有限的预算与时间内争夺业界最强模型（SOTA）。

## 核心玩法
- **人才市场**：从候选人列表雇佣员工，设定薪资并分配到不同部门，留意士气和跳槽风险。
- **模型训练**：配置训练策略、架构与周期，同时安排多个模型训练，消耗现金和 GPU 资源。
- **算力管理**：使用金币（现金）采购更多 GPU、扩容算力上限，平衡每月维护成本。
- **数据资产**：签约高质量语料和多模态数据包，提升训练效率的同时关注授权合规影响与维护费用。
- **市场合同**：根据模型成绩与合规评分争取企业客户合同，维持服务质量以获得持续的合同收入。
- **治理合规**：开展负责任 AI 审查、发布可信度白皮书，处理监管抽检与数据授权补签等事件，稳固公司声誉。
- **评估与发布**：在公开/私有基准测试上评估模型表现，决定是否发布、继续训练或重启项目。
- **竞争对手**：实时观察竞品在各大私有基准上的分数，制定追赶或超越策略。
- **财务循环**：每月结算基础收入、合同收入与固定支出，覆盖工资、GPU、数据维护等成本，领先模型和口碑可显著提升营收。

## 快速开始
1. 使用任何静态服务器（例如 `python -m http.server`）在仓库根目录启动服务。
2. 浏览器访问 `http://localhost:8000`，将设备调至横屏即可开始游戏。
3. 在人才市场招募员工，安排训练并进行评测，持续迭代以冲击 SOTA。

> 若在竖屏模式下访问，页面会提示旋转设备，以确保最佳布局体验。
